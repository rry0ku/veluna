Features

Built for listeners.
Not shareholders.

Every feature exists because someone asked for it — not because it harvests data.

YouTube Audio Streaming
Search and stream any track directly from YouTube — no account, no API key, no ads. Pure audio via yt-dlp.
Local Music Library
Import MP3, FLAC, and audio files. Veluna reads metadata tags and organises your collection automatically.
Offline Downloads
Save any track as high-quality MP3 in High (320kbps+), Medium, or Low. Listen anywhere, without internet.
Playlist Import
Import from Spotify via Exportify CSV or paste any YouTube playlist URL. Auto-matches every track. No login required.
Playlists & Queue
Create, edit, and reorder unlimited playlists. Full queue management with shuffle and repeat support.
Synced Lyrics
Real-time synced lyrics via LRCLib and Genius. Immersive full-screen lyrics view follows the track as it plays.
Sleep Timer
Set an auto-pause timer from quick presets (5m–90m) or a custom duration. Perfect for late-night listening.
Zero Telemetry
No analytics, no crash reporters, no data collection. Playlists, history, and settings stay on your machine only.
Backup & Restore
Export your entire library as a portable JSON file. Restore on any machine and pick up exactly where you left off.

FAQs

Everything you need to know about Veluna.

General
Yes. Veluna is 100% free and open-source. No paywalls, no premium tiers, no hidden fees — and never will be.
Veluna streams audio directly from YouTube using yt-dlp. Only the audio stream is extracted — no video is downloaded or rendered. You can also play local files (MP3, FLAC) from the Offline section.
No. Veluna uses yt-dlp directly — no YouTube account, no API key, no Premium subscription needed. Everything works out of the box.
Yes. Any track can be downloaded as MP3 — choose High (320kbps+), Medium (~128kbps), or Low. Downloaded tracks appear in the Offline section and play without internet.
Yes. Export your Spotify playlist via Exportify, then upload the CSV in Veluna. It runs up to 12 parallel YouTube searches to match every track. You can also paste any YouTube Music playlist URL directly.
Technical
On Linux, the installer script supports both DEB (Apt) and RPM (DNF) systems, installing dependencies (mpv, ffmpeg) automatically via your system package manager. On Windows, all binaries are bundled in the installer — nothing extra needed.
Internet is needed for YouTube streaming. Downloaded tracks and local files work completely offline through the Offline section.
Veluna is built on Tauri + Rust instead of Electron, so there's no bundled Chromium. This means a lightweight install that uses a fraction of the RAM of typical music players.
yt-dlp handles audio extraction. mpv is the audio engine, controlled via IPC socket on Linux and named pipe on Windows. ffprobe powers the Audio Info panel. Variable playback speed and loudness normalisation are piped directly into mpv's filter chain.
No. Zero telemetry, zero analytics, zero data collection of any kind. The only stats tracked are your local listening time — stored on your machine, never sent anywhere.
